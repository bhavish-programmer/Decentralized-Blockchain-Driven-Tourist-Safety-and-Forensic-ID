Purpose

AI + Blockchain for Tourist Safety & Forensic Trust

This system combines real-time people tracking, Re-ID matching, and tamper-evident blockchain logging to build a safety net for tourists. It prioritizes privacy by keeping sensitive data off-chain while storing cryptographic proof on-chain.

Real-Time Tracking Forensic Integrity Privacy-First

Current Demo Stack (In This Repo)

  • Flask + Socket.IO Real-time dashboard & APIs
  • YOLOv8n Person detection (CPU-friendly)
  • ByteTrack Multi-object tracking
  • OSNet x0.25 Re-ID embeddings
  • SQLite Encrypted PII (off-chain)
  • MongoDB Feature bank + sessions
  • Hyperledger Fabric DID + link proofs

Production Stack (Planned in README)

  • Fabric 2.5 Consortium ledger
  • Node Chaincode Smart contracts
  • PostgreSQL + Mongo Off-chain storage
  • Kafka + Flink Streaming pipeline
  • React / RN / Next UI + Mobile
  • Kubernetes Scale-out deployment

What Blockchain Solves

  • Immutable proof of DID registration
  • Audit trail for re-identification sessions
  • Multi-org governance for incident logs
  • Integrity without exposing raw PII

System Capabilities

Key strengths of the deployed demo and the planned production system.

Dual-Camera Tracking

Real-time detection and tracking across multiple feeds with ByteTrack.

Cross-Camera Re-ID

OSNet embeddings link identities across cameras with confidence scores.

Encrypted PII

PII is encrypted in SQLite; only hashes are written on-chain.

Blockchain Audit Trail

Hyperledger Fabric logs DID registration and tracking links.

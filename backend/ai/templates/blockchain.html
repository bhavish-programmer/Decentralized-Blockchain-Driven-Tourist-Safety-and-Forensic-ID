Purpose

Forensic Integrity for Tourist Identity & Tracking

This ledger captures cryptographic fingerprints of identity and re-identification events. It provides tamper-evident proof that a DID was registered and later linked to a tracking session, without exposing raw PII or biometric data.

Network Hyperledger Fabric
Channel tourismchannel
Chaincode tourist-safety

Tech Stack

  • Fabric v2.5 Permissioned consortium ledger
  • Node Gateway Express + Fabric SDK
  • Chaincode JavaScript smart contract
  • TLS CA-backed identities for Org1/Org2/Org3

Why Blockchain

  • Immutable audit trail for DID registration
  • Proof of tracking linkage with confidence score
  • Multi-organization endorsement for sensitive events
  • Off-chain PII, on-chain hashes only

Security Posture

  • DID, PII hash, and face hash are recorded only
  • Fabric CA manages identities
  • Ledger access is restricted by MSP roles
  • Gateway access is internal to this system
